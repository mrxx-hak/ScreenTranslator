# ALDA TRANSLATOR 2.0 — исходный Android-проект

Премиальный Android MVP: текстовый перевод, OCR изображений, снимок камерой, TXT/PDF, голосовой ввод, история, избранное и плавающая кнопка распознавания экрана.

## Совместимость
- Android 8.0+ (API 26+), включая Samsung A14 / Android 14.
- Root не нужен.
- Android Studio, JDK 17, Android SDK Platform 35.

## Сборка APK
1. Установите Android Studio и JDK 17.
2. Распакуйте архив и откройте папку `ALDA_TRANSLATOR` через Android Studio → Open.
3. Дождитесь Gradle Sync; установите Android SDK Platform 35, если будет предложено.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Функции этой версии
- **Текст:** ML Kit переводит китайский, русский, английский и турецкий. Модель скачивается при первом использовании, затем доступна офлайн.
- **Туркменский:** присутствует в списке интерфейса, но встроенная офлайн-модель ML Kit для него не поддерживается; перевод пока отключён, нужен отдельный онлайн-провайдер.
- **Фото:** выбор изображения → китайский OCR → перевод.
- **Камера:** системная камера возвращает preview-снимок → OCR → перевод.
- **Документы:** TXT напрямую; PDF распознаётся OCR постранично, максимум 5 страниц.
- **Голос:** системное распознавание китайской речи → перевод; требуется speech provider и разрешение микрофона.
- **Экран:** Android MediaProjection с системным подтверждением, плавающая кнопка, OCR по нажатию. Текст передаётся в приложение, где пользователь нажимает «Перевести».
- **История и избранное:** локальное хранение.

## Ограничения и безопасность
- Это исходный проект. APK не был собран и протестирован на физическом устройстве в этой среде; обязательно проверьте сборку и функции на телефоне перед использованием.
- Захват экрана не работает для некоторых защищённых/DRM-окон. Android показывает системное уведомление во время захвата.
- Камера использует системный preview, не полноразмерный файл.
- PDF OCR ограничен первыми пятью страницами и зависит от качества скана.
- Голосовое распознавание может обрабатываться системным или выбранным поставщиком речи.
- В текущем MVP нет автоматического перевода всех элементов интерфейса поверх исходного приложения: кнопка делает OCR, затем открывает ALDA с распознанным текстом.
